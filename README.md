# ShadBPA — downloads

Instaladores para Windows 10 e 11 (64 bits).

Baixe a versão mais recente em Releases. O instalador inclui WebView2 para uso offline. Após instalar a versão 0.8.1 ou superior, use Buscar atualizações na Home para consultar novas versões, confirmar e instalar pelo aplicativo.

As atualizações preservam o banco local e criam uma cópia de segurança antes de instalar. O aplicativo funciona offline; somente a consulta e o download de atualizações precisam de internet.

Este repositório contém somente instaladores, assinaturas e informações de atualização. O código-fonte é mantido em repositório privado. Nenhum cadastro ou documento de paciente é publicado.
